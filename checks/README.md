# Математические проверки

Sage: `just check-sage`. `quadratic-centralizer.py` проверяет пропущенное
слагаемое $D\lambda$ в формуле (8) главы I, §4. Вычисления точные,
в циклической кватернионной алгебре над полем рациональных функций
характеристики 2. Аргумент её делимости через чётность нормальных
порядков при $t=0$ приведён отдельно в комментарии сценария.

`normal-form-index.py` проверяет исправленный смешанный член конечной
квадратичной формы из I §16: ранги полярных матриц над GF(2) для p=2…8.
Печатная формула вырождена, исправленная имеет полный ранг. Перебор
проверяет этот индекс; классификацию форм он не доказывает.

`bounded-errata-tests.py` проверяет три контрпримера к печатным
утверждениям II §§9, 10, 12: пропорциональные изотропные векторы,
индексы в формуле (21) над F₂(t) и собственную центральную подгруппу
SO₆. Общую простоту проективных групп этот сценарий не доказывает.

`unitary-transvection.py` проверяет знак трансвекции в лемме 2 из
II §4 над рациональным и несколькими конечными полями. Общий аргумент
содержится в журнале исправлений; конечные проверки дополняют его.

`exceptional-matrix-action.py` проверяет действие из IV §8, п.8:
композицию, определитель и замену базиса символически над полем
рациональных функций с квадратичной инволюцией. Это проверка выписанных
формул, а не доказательство сюръективности на всю ортогональную группу.

Lean: `just check-lean`. Локально задайте `LEAN_MATHLIB` — уже собранный
checkout mathlib закреплённого коммита; команда ничего не скачивает.
В CI зависимости берутся из кэша mathlib. `lean-proofs.json` связывает
каждое доказательство с местом текста и указывает ограничения охвата.
Проверяются отсутствие предупреждений и `sorry`, состав деклараций и
аксиомы. Проверки охватывают перечисленные шаги, не всю книгу.

`just check-geometry` проверяет две векторные конструкции III §1 точной
рациональной арифметикой и 729 пар симметричных матриц порядка2 над F3
для формулы отклонения в III §3. Этот ограниченный пример дополняет
авторское доказательство. Сценарий также входит в `just check`.
